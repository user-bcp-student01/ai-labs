# HU-01 — Hallazgo pendiente relacionado con el token

## Origen

- No hay filas `Pendiente` en `HALLAZGOS.md` relacionadas directamente con el token de autenticación.
- `H-AUTH-03` (token Base64 sin firma) está marcado `Resuelto`, con evidencia `auth/src/main/java/com/bcp/workshop/auth/AuthTokenService.java:22-137`.
- `H-AUTH-04` (secreto y CORS) está marcado `Resuelto`, con evidencia `auth/src/main/java/com/bcp/workshop/auth/AuthTokenService.java:39-44` y `auth/src/main/resources/application.properties:4-9`.
- `H-AUTH-06` permanece `Pendiente`, pero corresponde a revisión SCA de dependencias; la fila no lo identifica como hallazgo del token y por ello no se usa como origen de esta historia.

## Contexto

La matriz del Día 1 no contiene un hallazgo pendiente del token que permita definir trabajo para HU-01 sin inventar alcance. Los hallazgos del token identificados en la matriz están resueltos. Esta HU registra la falta de origen y no solicita cambios de implementación.

## Ajustes necesarios

- No se derivan ajustes técnicos mientras no exista una fila `Pendiente` relacionada con el token.
- Si se identifica tal hallazgo posteriormente, actualizar la HU con el ID, la evidencia `archivo:línea`, el cambio aprobado y las pruebas correspondientes.

## Criterios de aceptación

- Al revisar `HALLAZGOS.md`, se confirma que ninguna fila `Pendiente` describe el token de autenticación; la única fila pendiente de auth, `H-AUTH-06`, es SCA de dependencias.
- No se planifica ni implementa un cambio de token como parte de HU-01 mientras no se registre un hallazgo pendiente aplicable en la matriz.

## Evidencia esperada

- `HALLAZGOS.md`, sección `Componente auth — Discovery`, con estados y evidencias de `H-AUTH-03`, `H-AUTH-04` y `H-AUTH-06`.
- Si aparece un hallazgo pendiente aplicable, su ID y cita `archivo:línea` deberán agregarse aquí antes de definir pruebas o implementar cambios.
